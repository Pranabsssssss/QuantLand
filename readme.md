# QuantStock — Landing Page

A modern, responsive landing page for **QuantStock**, a quantitative stock analysis and research platform.

🌐 **Live Website:** [quantstock.pranab.xyz](https://quantstock.pranab.xyz)

---

## About

**QuantStock** is a quantitative stock analysis platform designed to help users explore financial markets through data-driven research, analytics, and systematic strategies.

This repository contains the official **QuantStock landing page**, built to introduce the platform, communicate its core value proposition, and provide a clean entry point for users.

## Features

- Modern and responsive landing page
- Clean financial/quantitative design
- Responsive layout for desktop and mobile
- QuantStock branding and custom logo
- Lightweight frontend with minimal dependencies
- Fast-loading static website
- Production-ready deployment

## Tech Stack

- **HTML5** — Page structure and semantic markup
- **CSS3** — Styling and responsive layouts
- **SVG** — Scalable QuantStock branding
- **PNG** — Supporting brand assets

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Pranabsssssss/QuantStock-LandingPage.git
cd QuantStock-LandingPage
```

### Run locally

Since this is a static website, no package installation or build process is required.

You can simply open:

```text
index.html
```

in your browser.

For a better local development experience, you can also use a local HTTP server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
